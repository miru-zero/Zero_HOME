## Current status

## Promotion rule

Before any skill material becomes production guidance:

1. Decide whether it belongs in project docs, a ChatGPT skill, or runtime code.
2. Remove backup files or move them under `sandbox/`.
3. Add a README explaining ownership and use.
4. Commit only intentional files.

Do not silently treat skill drafts as active runtime code.
